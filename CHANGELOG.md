# Changelog

## 0.1.0 - First alpha release

Initial alpha release of Mindmap.

### Features

- Shared canvas for mind maps and linked notebooks
- Create, edit, drag, connect, duplicate, and delete nodes
- Compact, view, and edit node states with lock/unlock-style edit flow
- Left canvas panel for browsing, creating, renaming, switching, and deleting canvases
- Right panel for keyword search, tag filtering, entity inspection, and bulk tag edits
- Export and import of the SQLite database
- Undo and redo for canvas mutations
- Selection tools including select all, multi-select, copy, cut, and paste
- Keyboard navigation and shortcuts for moving around the canvas and focusing nodes
- Desktop packaging via Tauri alongside the web app
